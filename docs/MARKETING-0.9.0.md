# MagicStino OpenPlugin 0.9.0 — preview announcement

**Browse community VST plugins and install in a breeze**

Discover and install community plugins directly on your Akai Force touchscreen with OpenPlugin Manager 0.9.0. Browse the catalog, choose a plugin, and let the manager handle the installation.

- Build bigger arrangements with **16 audio tracks + 16 plugin tracks** in the Force image.
- Find plugins with A–Z, Z–A, Newest, Oldest and Popular sorting, plus alphabet shortcuts.
- Move supported manager-installed plugins from Internal to SSD or another suitable drive, and back. Files are verified before the original copies are removed to free space.
- See available drive space, progress during longer operations and useful errors when a drive is missing.
- Repair plugin skins from the manager, including existing installations with missing skins.
- Load the catalog much faster with PNG thumbnails. The owner’s Force test improved from roughly 20–45 seconds to about half a second.
- Keep remote access enabled or disabled across restarts, with connection details on screen.
- Find the version, manual, source and community credits in ABOUT.

The new Force image retains 16 audio + 16 plugin tracks (Tracks16) and adds permanent startup support for moved plugins. The 0.9.0 image has flashed and booted on the owner’s Force, and the manager’s ABOUT screen is confirmed. Storage across reboot, audio and track-limit acceptance on this exact image remain pending.

Original VST-method credit: NoQuestion and dustyslices, documented in the MPC-Forums proof-of-concept discussion in September 2026.

Built on poloq’s original Plugin Manager and sd88me’s Open MPC catalog and tooling. Thanks to MockbaTheBorg / MockbaMod for SSH, screen and mouse resources, and to no3z, Amit Talwar and bonsaipanda for the mouse code. Original authors’ credits and licenses remain intact.
